# Evaluation repository

Keep tests, fixtures, historical evidence, and evaluation tooling here. The Pancake Stack checkout is a read-only input selected by PANCAKE_STACK_SOURCE or run_checks.py --source. Do not change that checkout from tests. Retain exact source and evaluator revisions in results and distinguish dirty worktrees. Historical helper tests use fixtures/legacy-0.19.3, never user preferences. Live model trials require task authorization, isolated profiles, bounded execution, and private raw records. Do not publish, install plugins, or modify global settings as part of checks.
