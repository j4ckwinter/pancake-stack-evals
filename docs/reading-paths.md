# Delegation reading paths

The candidate removes repeated coordination details without adding another reference. Parallel-work owns assignment, isolation, launch reporting, and integration. Direct parallel-work readers reach host-runtime and change-review without returning through the whole Pancake router. Entry-point and independent-review rules remain in place.

The report uses complete source bodies returned by tools, including repeated returns. It does not measure tokens, speed, attention, or broad efficacy. Partial, truncated, and reformatted bodies remain unmeasured. Matching embedded bodies can overlap; inspect each reported path before interpreting totals.

Two paired tasks cover a small refactor and a compatibility change. Each arm uses a fresh isolated profile, frozen source, identical case, no model or effort override, and a 240-second bound. Presentation order is reversed for the second task. The compatibility case permits independent read-only review; the small case disables delegation.

An initial small-refactor baseline completed successfully but was excluded because evaluator finalization changed its captured input identity. It remains in private records. A fresh complete comparison follows frozen inputs. The first package run likewise passed its tests but failed input stability and was repeated.

## Reproduce

Use the existing `behavioral.compare.run_trial` with `workflow_cases.CASES['small-refactor']` and the Pancake repair adapter from `entrypoint_compare.entrypoints()[1]`. Freeze both source directories with `snapshot-origin.json`. Record source/evaluator identity before and after every run. Run the reading helper against only that trial's retained session paths:

```sh
python3 -B tests/behavioral/reading_paths.py --source /path/to/frozen-source --sessions /private/run/session.jsonl --output /private/run/reading.json
```

Raw records stay private. No installation, native discovery, model diversity, Claude workflow, large-work delegation, or competing-design behavior is established by these two cases.
