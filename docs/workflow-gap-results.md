## Refactor sequencing

Four runs in two pairs used the same small Python refactor with two repetitions per source variant. The original workflow ran the existing unittest only after editing in both runs. The revised workflow ran it before the first edit and after the last edit in both runs. A separate assessor received shuffled labels and ordered command outputs without the variant mapping and confirmed those observations. This was partial blinding because source paths and response style can reveal treatment.

All four implementations passed the fixed numeric, empty-input, iterator, and invalid-input probes and preserved unrelated fixture files. This establishes the observed check sequence on this fixture, not a general correctness advantage. The added paragraph contains 37 whitespace-separated words.

Independent harness review found that the copied skill bundle was checked before launch but not after execution. The focused workflow adapter now records post-run bundle preservation and rejects a changed bundle. A mocked mutation regression covers the guard. A separate final paired smoke run repeated the sequencing result and recorded both bundles unchanged. Its evaluator identity is separate from the initial four-run comparison.

This supports retaining the extraction for these cases, not general review superiority.

## Observed reading paths

The refactor runs returned the complete text of six guidance files. Their unique whitespace word count was 4,077 before the baseline rule and 4,114 afterward. Ordinary clean review returned 793 words before extraction and 610 afterward. The revised ordinary-defect review also loaded the specialist reference, returning 807 words. All revised comment and suppression reviews returned that reference as expected, also totaling 807 words. Thus entrypoint reduction did not consistently reduce observed reading volume. No further host-runtime or implementation extraction was accepted on this evidence.

An ordinary empty-input CLI fix passed fixed artifact checks in both arms and added a regression test. The before-extraction run returned 4,603 guidance words. The after-extraction run returned 4,913, including Fix guidance that the other run did not load. Both loaded Check; neither loaded its specialist reference. This pair does not isolate the extraction's effect on total reading volume.

Some runs issued parent-directory AGENTS.md discovery commands. The evidence records these separately; complete-text matching cannot establish that all discovery stayed inside the candidate directory.

Read-path evidence identifies complete source-file text present in retained command output. It does not infer reads from filename mentions or directory listings. Compound commands can return nonzero after successful content reads; their output must support the observation separately. Partial or truncated reads remain outside the complete-text word count. These observations do not establish exhaustive filesystem access, exact context consumption, or causal token savings.

## Method and limits

Source bundles were frozen with original revisions, dirty-state records, and file hashes. The runner checked source and evaluator identity before and after each trial. Trials used private temporary Codex profiles, bounded execution, no model or effort overrides, and disabled delegation in the focused refactor and Check comparisons. The ordinary-fix pair retained the existing workflow runner's delegation policy. Authentication was removed before retaining raw sessions. No plugin was installed or global preferences changed. Raw sessions and projects remain private outside both repositories.

Only the corrected harness records post-run bundle preservation. Earlier runs retain that limitation. Review findings are assessed separately from preserved artifacts, completed execution, and usage. Samples are small synthetic tasks except for the historical repository fixture. One host and model cannot establish host parity or model diversity. Timing and token counts are observations, not invoices or causal efficiency estimates. Claude workflow verification is excluded.
