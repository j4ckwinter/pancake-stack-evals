The current-source Codex CLI smoke trial passed on 2026-10-14. Both proposal launches and the separate judge launch explicitly used `fork_turns="none"`. Each returned an accepted role identity and a linked session containing its own final response and task completion. The judge started after both proposals completed. The organic task requested independent designs for a persistent local Python queue with concurrent producer and consumer processes. The lead's user prompt strongly preferred JSON but explicitly called it a preference rather than a fixed requirement. Both candidates recommended SQLite with nondestructive claim. The separate judge endorsed that convergence and identified acknowledgement-policy differences and a potential ID-reuse problem in one filesystem alternative. Convergence is not evidence of distinct primary architectures.

The parent reported the same model with null effort. This provides no model or provider diversity evidence. The read-only run used an isolated `CODEX_HOME` containing a private authentication copy. The credential and profile were removed in cleanup. Raw records remain private outside both repositories.

The Prove It Works principle shaped verification. The verdict comes from actual launch and linked completion records, not the lead's self-report. Task-message bodies are encrypted in those records, so the full neutral brief and withheld preference or author identities cannot be audited. Fresh-context invocation and host acceptance were observed; host context internals were not independently instrumented. This single current-source run has no baseline or replication and supports no causal improvement claim. Queue designs remain proposals; their suggested runtime checks were not executed.
