The separately identified [19 October follow-up](historical-review-followup.md) reviews the latest Boolean-corrected control. Its observations do not replace or pool with this batch.

Baseline and Pancake each detected **0/2 instances of the selected historical defect**. Both found genuine additional assessor gaps. The original target-repaired control was not clean, so **clean specificity and clean false-positive rate are unavailable**. This batch establishes no superiority for either arm.

## Calibrated follow-up

Two additional runs used evaluator `31f54ce` after the three demonstrated assessor gaps were corrected. A small adapter selected only `migration-clean` through the existing runner; its exact source, manifest, input hashes, settings, metrics and responses are retained in [follow-up evidence](evidence/calibrated-control-2026-10-14.json). This was a posthoc calibration check with one run per arm, not a second effectiveness comparison. Both runs completed and preserved their workspaces and inputs.

Baseline reported no actionable regression. Pancake reported two concerns. Independent full-assessor reproduction confirmed that readers accepting `False` could still pass while retaining the original tests. The current assessor and calibrated artifact now include both booleans in their malformed-value probes, with separate reader/version regressions. No further live run is claimed after this bounded correction.

The other concern was that added Python and Markdown files are permitted. The allowance reproduced, but it is not established as a regression. The task requires unrelated existing files to remain unchanged, while valid migrations can need new shared modules and documentation. Filename restrictions cannot establish semantic relevance and would risk reinstating the selected historical defect. This remains an automatic-assessment boundary requiring review of the actual change.

The follow-up therefore does not establish clean-control specificity either. Its original calibrated inputs and responses are retained rather than relabeled after the Boolean correction. The fixture is a target-repaired, calibrated control with known assessment boundaries, not proof that every possible incorrect migration is rejected. Earlier published migration results retain their original assessor identities and are not retroactively validated by these corrections.
